# CMPM 121 D3 Project

In this game much like 2049 and Pokemon Go, players move about the real world collecting and depositing items in locations that are only interactable when the player is sufficiently close to them. Being able to click and combine numbers of the same value to craft a larger number.

The game is played across the cells of a rectilinear latitude–longitude grid, spread out over the surface of the planet Earth. The cells the player can see stretch around the entire world but they can only interact with cells in a cirlce around them.

Players can play using real life movement or button based movement, and can restart there game at any time. If the player refuses GPS then they will default to the school classroom.
